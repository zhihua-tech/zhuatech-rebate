# 知华渠道返利结算

> 让每笔返利都有销售、回款和审批依据。

由 [知华科技（上海如静知华信息科技有限公司）](https://www.zhuatech.cn/) 提供的 Java + H5 前后端分离企业软件社区源码版，数据库为 MySQL。

## 一条完整的业务链

伙伴建档 → 返利协议审批 → 销售单与回款核销 → 销退调整 → 自动汇总结算 → 独立审批 → 付款核销

以实际收款减销退的净额计算返利，自动选择基础/达档档位，逐销售单按分四舍五入。结算锁定销售归属，阻止重复计提；驳回会释放占用并冲销旧明细。

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 渠道伙伴 | 渠道等级与结算资料 | 新建、编辑、查询、详情、导出 |
| 返利协议 | 以实收销售额为基础的分档返利规则 | 审批生效、终止新增 |
| 销售核销 | 回款确认与销退净额 | 回款核销、销售退货、作废 |
| 返利结算单 | 自动汇集未结算实收销售并应用档位 | 锁定并计算、审批结算、驳回并释放、付款核销 |
| 返利明细 | 每笔销售的计提金额、净销售与结算占用 | 业务动作自动生成、查询、追溯、导出 |

- 后端：Java 21 / Spring Boot 4.0.7 / JDBC / Flyway / MySQL 8.4，包名 `cn.zhuatech.rebate`。

### 明确的功能边界

一期按单协议、单伙伴、单结算区间实行统一档位返利，不含跨协议叠加、阶梯累进、税务发票与银行代付。外部 ERP 销售导入需通过 API 对接。

这是一套可运行、带业务测试的初版实现；测试通过不等于完成了所有生产环境的容量、安全、监管或现场验收。上线前需结合真实数据、业务制度和基础设施进行实施验证。

# 主要功能验收矩阵

上海如静知华信息科技有限公司 · https://www.zhuatech.cn/

## 验收目标

伙伴建档 → 返利协议审批 → 销售单与回款核销 → 销退调整 → 自动汇总结算 → 独立审批 → 付款核销

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 渠道伙伴 | 渠道等级与结算资料 | 新建、编辑、查询、详情、导出 |
| 返利协议 | 以实收销售额为基础的分档返利规则 | 审批生效、终止新增 |
| 销售核销 | 回款确认与销退净额 | 回款核销、销售退货、作废 |
| 返利结算单 | 自动汇集未结算实收销售并应用档位 | 锁定并计算、审批结算、驳回并释放、付款核销 |
| 返利明细 | 每笔销售的计提金额、净销售与结算占用 | 业务动作自动生成、查询、追溯、导出 |

## 界面验收

检查业务端模块列表、新建与详情、服务端错误反馈，以及管理端账号权限和审计入口；桌面截图及管理端截图见 README。所有演示金额和人员均为虚构。

## 不宣称已覆盖的事项

一期按单协议、单伙伴、单结算区间实行统一档位返利，不含跨协议叠加、阶梯累进、税务发票与银行代付。外部 ERP 销售导入需通过 API 对接。

不将本机测试当成真实生产负载的压力测试，也不声称通过安全合规认证、故障切换或客户现场验收。测试事实见 [测试结果](TEST-RESULTS.md)。

## 增补安全与并发回归

四个不同请求同时修改同一版本，只允许一个成功；五次密码错误后暂时锁定；另一企业的 HTTP 会话无法读到单据、审计或附件；同一秒创建的记录使用数据库顺序号确定先后。
